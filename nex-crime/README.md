## ⚖️ Core Product Principle: Decision Support, NOT Autonomous Policing

This platform is strictly an **investigative decision-support system**. The interface never asserts:
> *"AI has proven this person is guilty."*

Instead, NexCrime enforces a transparent three-tier evidence hierarchy:
1. **RAW DATA RECORD:** Direct immutable ingest from registered FIRs, bank statements, or carrier CDR dumps.
2. **AI-INFERRED RELATIONSHIP:** Probabilistic multi-hop inferences, spatio-temporal co-locations, or vector similarity matches with confidence scores.
3. **HUMAN-VERIFIED EVIDENCE:** Formal findings verified and digitally countersigned by credentialed investigating officers.

## ⚡ Quick Start Guide

### 1. Prerequisites
- **Node.js** (v18+) OR **[Bun](https://bun.sh)** (recommended, blazing fast)
- Modern web browser (Chrome, Edge, Firefox, Brave)

### 2. Install & Run Frontend
```bash
# Clone repository
git clone https://github.com/<YOUR_USERNAME>/nexcrime.git
cd nexcrime

# Install dependencies (using Bun or npm)
bun install
# or: npm install

# Start local development server
bun run dev
# or: npm run dev
```
Open **`http://localhost:5173`** in your browser.

### 3. Production Build & Preview
```bash
bun run build
bun run preview
```

### 4. Optional: Run FastAPI Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
```
Backend runs at `http://localhost:8000`.  
Swagger interactive docs available at `http://localhost:8000/docs`.

- **Synthetic Data Disclosure:** All entity records, phone numbers, vehicle registrations, corporate names, and locations within this demonstration build are **fictional and synthetic**. No actual personal, classified, or real-time police database is accessed.
